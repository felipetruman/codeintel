# CodeIntel v0.6.0 verification — 2026-09-09

Scope: versioning changes based on `b49c901926ac32089698a48dfe27adf10f42aa80`,
plus the interface proof in this PR. The Rust runtime source is unchanged.
The release binary reports `codeintel 0.6.0`; MCP initialization reports `0.6.0`.

## Reproduce

Requires Python 3.11+ and the Rust toolchain. From the repository root:

```sh
cargo build --release --locked
python3 docs/verification/prove_interfaces.py
```

`CODEINTEL_BINARY` can select a different build; its reported version must match
this checkout's Cargo.toml. The suite uses temporary repositories and the real
CLI/MCP stdio transport. It does not call Claude, Codex, or any hosted model.

## Interface evidence

All **17 tests passed** locally. The same suite runs in the `Verify` workflow.

| Interface | Verified behavior |
| --- | --- |
| CLI `index` | Builds indexes; unchanged source is reused. |
| CLI `search` | Literal and regex matches, limit, empty results. |
| CLI `context` | Relevant file returned with a limit. |
| CLI `symbols` / `symbol` | Filtered definitions, callers, unknown symbol. |
| CLI `graph` / `impact` | Ranking, graph limit, depth-limited blast radius. |
| CLI `doctor` | Missing/fresh state; no index creation or byte changes. |
| CLI `serve` | Watcher persists source edits; process is terminated and reaped. |
| CLI `mcp` | Real JSON-RPC over stdin/stdout; clean exit on stdin EOF. |
| MCP `code_search` | Literal/regex, explicit path, result limit. |
| MCP `code_context` | Newly added source discovered without manual indexing. |
| MCP `code_symbol` | Definitions, callers, and callees. |
| MCP `code_impact` | Depth limit and refresh after adding a caller. |
| Protocol/errors | Initialization, notifications, ping, exact tool discovery, missing arguments, unknown tool/method, session recovery. |
| CLI help/errors | Every command's help, version, missing argument, unknown command, invalid regex. |

The fixture contains `outer -> middle -> leaf`; expected callers and impact
sizes are asserted explicitly. `serve` is checked through persisted state,
without querying an interface that could refresh the index on its behalf.
