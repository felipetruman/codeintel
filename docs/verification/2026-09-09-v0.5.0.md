## Reproduce the functional proof

From the repository root, build the release binary and run the standalone
standard-library Python script:

```bash
cargo build --release --locked
python3 docs/verification/prove_core.py
```

The script creates a temporary three-file Python repository, checks search,
symbol lookup, context output, and graph impact, edits one source file, then
checks incremental reuse. It removes the temporary repository automatically.
It raises an assertion or exits nonzero if the expected behavior is absent.
